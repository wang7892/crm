# 智能问数 Text-to-SQL

普通问数统一使用模型直接生成 SQL。原先由固定问法生成查询计划和调用业务工具的主入口已移除。

生成过程沿用 SQLBot 的关键词提取、术语同义词扩展、表结构检索、真实样例、术语与 SQL 示例、最近 3 轮用户/SQL 上下文，以及原生 SQL 提示词。支持现有内置 CRM 表和已配置的 MySQL、PostgreSQL、Oracle、SQL Server、文件数据源。

模型 SQL 由已有 AST 编译器进行只读验证和权限处理。执行记录对外展示模型原始 SQL，不展示权限改写 SQL、绑定参数或连接凭据。不同物理连接不能在一条 SQL 内跨库关联。

失败保存 SQL 和执行反馈，由用户点击“重新生成”或继续提问；没有自动修正循环或置信度阈值拦截。业务口径由表结构、注释、术语与 SQL 示例提供，问数主流程不额外执行旧查询计划的业务语义校验。

结果以列元数据和真实行保存，再独立生成图表配置。支持表格、柱状图、条形图、折线图、饼图、显式分析、预测数据、推荐追问和 Excel 导出。接口及配置见 AI_Agent_SQLBot_Enhancements.md。
