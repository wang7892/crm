# 问数多轮查询、分析与预测

问数直接把最近 3 轮原始用户问题和模型 SQL 回复传给 SQL 生成模型。比如先问“今年各月收入”，再问“只看华东呢”，第二问保持原文，由同一个 SQL 生成步骤结合历史条件生成新查询。

每条成功查询返回结构化表格，可使用“分析”“预测”“重新生成”和“导出 Excel”。推荐追问来自 SQLBot 原生猜测问题模板，不使用固定问题路由。

分析和预测只读取所引用的服务器保存结果，不要求客户端回传数据，也不自动生成补查查询。预测结果单独保存为未来周期的数据行；可以绘制趋势时，图表区分历史数据与预测线段。模型判断无法预测时显示其说明。

重新生成沿用原问题、原数据源和已保存的执行失败反馈，SQL 历史截至原记录之前。查询失败不会自动执行修正 SQL。权限、组织或数据源版本发生变化时，历史结果必须重新查询。

详细接口、配置及对齐范围见 AI_Agent_SQLBot_Enhancements.md。
