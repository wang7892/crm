# 智能体数据源配置

## 操作入口

Web 智能体页面左侧「配置」进入数据源管理。

1. 新建数据源，选择 MySQL、PostgreSQL、Oracle、SQL Server 或 Excel/CSV。
2. 填写连接信息并测试连接，或上传本地表格文件。
3. 选择数据表、查看字段并保存。
4. 返回聊天，在顶部选择数据源，再提出查询问题。成功查询的回答右上角 SQL 图标展示模型生成的原始 SQL，并按数据库方言排版。

列表支持名称搜索、类型筛选、编辑连接、重新选表和删除。新上传的文件在选表保存前不会出现在聊天可用数据源中；取消配置会删除本次未保存的文件数据源。

内置 CRM 仍使用原有组织、负责人、字段脱敏等权限。外部数据源不使用 CRM 的逻辑实体或 CRM 权限改写，模型根据所选表的真实结构生成 SQL。切换数据源会创建新聊天。

## 数据库连接字段

| 类型 | 默认端口 | 数据库字段 | Schema 默认值 |
| --- | --- | --- | --- |
| MySQL | 3306 | 数据库名称 | 数据库本身 |
| PostgreSQL | 5432 | 数据库名称 | public |
| Oracle | 1521 | Service Name，非 SID | 用户名大写 |
| SQL Server | 1433 | 数据库名称 | dbo |

Oracle 分页要求 12c 及以上，SQL Server 分页要求 2012 及以上。主机填写 IPv4 地址或域名，不能填写 JDBC URL、连接参数或实例名。SQL Server 命名实例应填写实际 TCP 端口。IPv6、SSH 隧道、Oracle SID、跨 Schema 查询暂不支持。

SSL/TLS 开启后验证证书，不提供跳过校验选项。需要将相应 CA 配置到服务器/JDBC 驱动支持的信任存储。MySQL 默认关闭公钥自动拉取；使用 caching_sha2_password 的账号应启用 TLS 或在服务器正确配置公钥，不要改用允许自动拉取来绕过校验。

**必须使用仅有必要表/视图 SELECT 权限的独立数据库账号，不要使用 root、sa 或 CRM 应用的写账号。** 外部数据源可查询的数据范围由该账号决定，不能继承 CRM 的行级权限。敏感列应通过只读视图排除。数据库视图及同名自定义函数的行为也必须由可信管理员审查。

连接和查询由后端服务器执行，浏览器能访问数据库不代表后端能访问。连接超时约 10 秒，查询超时 30 秒。当前只列出一个数据库/Schema 中的表和视图；最多 500 张表、每表 256 列、选中 60 张表，模型提示词结构总量最多 12 万字符。

## Excel / CSV

- 支持 `.xlsx`、`.xls`、`.csv`，文件最大 20MB，总数据单元格最多 20 万个，每表最多 256 列，Excel 最多 30 个工作表。
- 每个工作表第一行为表头。表头不能为空。CSV 每一行列数必须与表头一致；支持标准带引号的逗号、换行及 UTF-8 / GB18030（兼容常见 GBK 文件）。
- Excel 各工作表成为 `table_1`、`table_2` 等表，工作表名称保留为表注释。合法英文表头作为列名；中文及其他表头转为 `col_1` 等稳定列名，原表头保留为字段注释。
- 数值、布尔值、ISO 日期/时间自动推断；混合类型作为文本。数值使用 `DECIMAL(38,12)`，超过范围会拒绝导入；前导零文本不会转换为数字。公式使用文件中已有的缓存值，不执行公式或外部链接。
- 导入的是上传时的独立快照，不会自动读取电脑上的源文件。更换文件应新建数据源。
- 服务端持久化为 H2 文件库，实际查询使用只有 SELECT 权限的独立账号，重启后仍可查询。

## 权限与存储

接口要求已登录和智能体读取权限；配置、测试连接、上传、选表保存和删除额外要求 `AGENT:UPDATE`。每个数据源仅创建者本人、原组织可访问，当前没有共享数据源功能。授予 `AGENT:UPDATE` 等同于信任用户配置后端可连接的数据库地址，请限制该权限和服务器出口网络。

密码使用 AES-256-GCM 加密并持久化随机 nonce。列表、编辑返回和模型提示词不会包含密码；编辑时空密码表示保持原密码。数据源密码不写入 URL 或日志。

服务端配置项：

```properties
crm.ai-agent.datasource.storage-path=E:/CRM/runtime/ai-agent/datasources
```

不配置时使用后端工作目录下的 `runtime/ai-agent/datasources`。目录包含 `connection.key` 和导入文件库，首次保存时自动生成密钥。请使用固定的绝对路径、限制为后端服务账号访问，并将目录配置为持久化存储。

**数据库配置记录和 connection.key 必须一起备份，文件数据源还需要备份对应 `.mv.db` 文件。** 更换工作目录或丢失密钥后，已有数据库密码无法解密；系统不会静默生成新密钥来替换旧密钥。不要提交运行目录、密钥或文件数据库到 Git。

所有模型 SQL 都经过单 SELECT AST 校验，只能访问选中表；禁止写语句、锁、系统表、数据库链接和非白名单函数。分页通过服务器生成 SQL 完成。历史分析和续页凭据绑定用户、组织、数据源 ID 和配置版本，编辑或删除数据源后旧凭据失效。正在执行的查询会在连接前再次核对所有权与版本。

查询结果每字段最多 8000 字符、每页结果文本最多 50 万字符，不支持二进制或大文本 LOB 输出。SQL 校验/执行失败最多请求模型修复一次，不回退到内置 CRM 查询。

## 部署与验证

需重新构建并重启后端；Flyway 自动执行 `V1.6.0_53__ai_agent_datasource.sql`。Web 开发服务器刷新后加载新界面，部署版本需重新构建 Web。Mobile 原有内置 CRM 查询保持不变，数据源管理入口本次仅在 Web 提供。

本次已打包的新版本为 `backend/app/target/datasource-build/app-datasources.jar`，没有覆盖运行中的 `app-main.jar`。先正常停止旧后端，再在项目目录执行以下命令，沿用现有配置和启动参数：

```powershell
.\start-backend.ps1 -JarPath "backend\app\target\datasource-build\app-datasources.jar"
```

不传 `-JarPath` 时，启动脚本仍使用原来的 `app-main.jar`。仅刷新前端不能启用新的数据源接口，必须先启动新后端。

自动测试覆盖文件真实查询/汇总/分页、文件持久化及只读账号、选表限制、跨用户/组织拒绝、密码保留与加密、配置版本、五种方言分页、SQL 安全拦截、模型 schema 提示词与 CRM 路由隔离。真实 MySQL/PostgreSQL/Oracle/SQL Server 网络、驱动和账号兼容性仍需在对应测试数据库验证，不使用生产数据库进行自动测试。
